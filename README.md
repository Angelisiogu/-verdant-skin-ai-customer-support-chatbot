Verdant Skin Co. AI Customer Support Chatbot

An AI-powered customer support chatbot developed as part of the AfriMent Cohort 23 internship project for Verdant Skin Co., a skincare brand.

The chatbot helps customers get answers to common company and product-related questions. When it cannot confidently answer an enquiry, it collects the customer’s contact details and captures the unresolved request in Airtable.

An automated email notification then alerts the support team, making it easier for a human agent to review and follow up.

Key Features

* AI-assisted responses to common customer enquiries.
* Customer detail collection for unresolved questions.
* Airtable integration for support request tracking.
* Automated email notifications to support agents.
* Human-in-the-loop escalation for enquiries requiring further assistance.

Tools & Technologies

* Zapier
* Airtable
* AI by Zapier
* Email Automation


🔗 [Live Chatbot Demo](https://verdant-support-assistant.zapier.app)

Project Purpose

To improve customer support by combining AI-powered responses with a structured human escalation process.
